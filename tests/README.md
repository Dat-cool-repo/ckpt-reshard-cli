# Tests

| Suite | Needs | Data |
|---|---|---|
| `src/**` unit tests + [`cli.rs`](cli.rs) | Rust only (`cargo test --release`) | the committed tiny fixtures in `fixtures/tiny` |
| [`test_roundtrip.py`](test_roundtrip.py) | CPU torch, transformers, safetensors, pytest | DCP/HF fixtures generated into `$CKPT_FIXTURES` |
| [`test_formats.py`](test_formats.py) | as above, plus megatron-core and deepspeed for the Megatron/DeepSpeed tests | Megatron/DeepSpeed fixtures generated into `$CKPT_FIXTURES/{megatron,deepspeed}` |

`scripts/test_all.sh` sets everything up and runs all of it. `$CKPT_FIXTURES` defaults to
`<repo>/data/fixtures`, which is git-ignored. The pytest fixtures are generated on first use.

## Committed fixtures (`fixtures/tiny`, about 1.3 MB)

Every file here is a **toy model generated by this repository's own scripts** from random
initialisation with fixed seeds. They contain no pretrained or third-party weights and no data. The
models have hidden sizes of 12–16 and vocabularies of 37–64. Every tensor holds random
initialisation values, in most fixtures after one or two optimizer steps on random inputs. The
largest file is about 108 KB.

| Path | Made by | Contents |
|---|---|---|
| `dcp_fsdp/`, `dcp_fsdp_st/`, `dcp_2d/`, `hf_sharded/`, `reference/`, `reference_2d/`, `reference_optim/` | `scripts/make_fixtures.py --layers 1 --embd 16 --vocab 37 --positions 8 --hf-shard 4KB` (4 gloo ranks) | Random 1-layer GPT-2 (`torch.manual_seed(1234)`) after one Adam step: FSDP2 DCP with model and optimizer state, DCP with safetensors chunks, a 2-D `Shard(0)+Shard(1)` bf16 DCP, `save_pretrained` shards and full-tensor references |
| `megatron/legacy/`, `megatron/torch_dist/`, `megatron/reference/` | `scripts/make_megatron_fixtures.py --tiny` (megatron-core, TP2/PP2, 4 gloo ranks) | Random 2-layer GQA GPT, hidden 16, vocab 50 padded to 64, in Megatron-LM's legacy and `torch_dist` formats, plus megatron-core's own TP=1 gather as `reference/model.safetensors` |
| `deepspeed/zero2/`, `deepspeed/zero3/` | `scripts/make_deepspeed_fixtures.py` (DeepSpeed, 3 gloo ranks, bf16) | Random toy module (embedding 37×12, a few linears, a frozen layer, a tied weight, a buffer) and DeepSpeed's own `zero_to_fp32` output as `reference.safetensors` |

torch records the absolute directory a DCP checkpoint was saved to in `.metadata`
(`storage_meta.checkpoint_id`). The generators strip it to the directory name with
`scripts/scrub_dcp_metadata.py`, so no local paths end up in the fixtures. The Megatron `args`
contain `save="/nonexistent"` and no other absolute paths, user names or host names.

## Malicious-pickle tests

The safety tests check that `ckpt` refuses pickles that would execute code, and that the code never
runs. **No malicious file is committed to the repository.** Each payload is built at test time inside
a temporary directory, never in the repository tree. Every payload is the same harmless command: `os.system`
(`posix.system`) called with `touch <tmpdir>/pwned`, which would only create an empty marker file.
The tests assert that `ckpt` exits with code 2 and `refusing pickle global ...`, and that the marker
file does not exist.

| Test | Where the payload is placed |
|---|---|
| `cli.rs::malicious_metadata_refused` | A 43-byte protocol-2 pickle, `posix.system("touch pwned")`, written as a DCP `.metadata` in a temp dir. It is an escaped byte-string literal in the source. |
| `test_roundtrip.py::test_malicious_metadata_is_refused` | `pickle.dumps` of an object whose `__reduce__` returns `(os.system, ("touch <tmp>/pwned",))`, as a DCP `.metadata`. It also covers a copy of a valid DCP whose first chunk pickle's `torch._utils._rebuild_tensor_v2` global is rewritten to `posix.system`. |
| `test_formats.py::test_megatron_malicious_rank_file_refused` | The same object `torch.save`d as a Megatron `model_optim_rng.pt` |
| `test_formats.py::test_deepspeed_raw_and_errors` | The same object inside a DeepSpeed optimizer-state file |

Python never unpickles these files: they are written with `pickle.dumps` / `torch.save` and only read
by `ckpt`.
